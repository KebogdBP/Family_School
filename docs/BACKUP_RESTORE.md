# Резервное копирование и восстановление HomeEdu

## Локальная проверка

Docker-контейнеры должны быть запущены. Создать копию основной локальной базы:

```bash
npm run db:backup:local
```

SQL-файл создаётся с правами `0600` в каталоге `backups/`, который исключён из Git. Проверить копирование и восстановление без изменения основной базы:

```bash
npm run test:backup-restore
```

Проверка создаёт временную базу `homeedu_restore_test`, восстанавливает в неё дамп, сравнивает список таблиц, точное число строк и контрольные суммы, а затем удаляет только временную базу.

## Production / Beget

Пароль нельзя писать в команде или сохранять в репозитории. Перед миграцией или релизом:

```bash
read -s MYSQL_PWD
export MYSQL_PWD
umask 077
mysqldump --host="$DB_HOST" --user="$DB_USER" --single-transaction --routines --triggers --default-character-set=utf8mb4 "$DB_NAME" > "homeedu-$(date +%Y%m%d-%H%M%S).sql"
unset MYSQL_PWD
```

Восстановление всегда сначала проверяется в отдельной базе:

```bash
read -s MYSQL_PWD
export MYSQL_PWD
mysql --host="$DB_HOST" --user="$DB_USER" "$RESTORE_DB_NAME" < homeedu-YYYYMMDD-HHMMSS.sql
unset MYSQL_PWD
```

После восстановления нужно проверить `schema_migrations`, количество профилей, вход родителя и один учебный маршрут. Замена рабочей базы допускается только после этой проверки.

## Приватные файлы

SQL-дамп не содержит фотографии и PDF. Каталог `apps/api/storage/uploads` (в production — `private/uploads` вне `public_html`) копируется отдельно в зашифрованное хранилище. Дамп базы и архив файлов должны иметь одинаковую отметку времени. Доступ к ним разрешён только владельцу аккаунта хостинга.

Минимальная политика хранения для семейного пилота: семь ежедневных и четыре еженедельные копии. Неиспользуемые копии удаляются безопасно после проверки более новой резервной копии.
